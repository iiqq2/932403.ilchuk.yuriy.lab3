Страница продолжает лабораторную №2: сохранены бирюзово-белое оформление, переключение RU/EN по нажатию, навыки, проекты и описание EngCLI. Добавлены карточки языков и галерея фраз.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

При необходимости запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.

## Выполненные требования

| Требование | Реализация |
| --- | --- |
| Горизонтальное адаптивное меню на Flexbox | `.page-nav`: `display: flex` и `flex-wrap: wrap` |
| Три Flex-карточки языков | `.language-cards` и `article.language-card`: флаг, название и уровень |
| Grid-галерея «Фраза недели» | `.phrase-gallery`: три колонки и две общие строки; три `article.phrase-card`, каждая занимает две строки |
| Оригинал, перевод, транскрипция и аудио-иконка | Три фразы на английском, испанском и французском |
| Адаптивность 1/2/3 | Карточки Flex и галерея Grid имеют 1 колонку до 600 px, 2 до 960 px и 3 на широких экранах |
| Отсутствие горизонтальной прокрутки | Перенос меню и текста, `min-width: 0`, `minmax(0, 1fr)`, адаптивные поля |
| Семантические карточки | `article` с заголовками; группы расположены в `section` |
| Атрибуты `lang` | У оригиналов `en-GB`, `es-ES`, `fr-FR`; у транскрипций — языковые теги с `fonipa`; у переводов обновляется `ru`/`en` |
| Контраст текста ≥ 4.5:1 | Тёмные тексты и ссылки на белом и светлом бирюзовом фоне; обе языковые темы |

У Grid-карточек две части: оригинал и подробности. `subgrid` выравнивает их по общим строкам. Для браузеров без `subgrid` оставлена обычная внутренняя Grid-сетка `auto 1fr`.

## Учебное содержание

Основной изучаемый язык из предыдущих работ — английский. Уровни B1/A1 и дополнительные языки в новых карточках являются демонстрационными данными для макета, а не подтверждёнными сведениями о студенте.

В галерее представлены английское «Thank you!», испанское «¡Hola!» и французское «Bonjour !» с переводами. Ссылки на словарные статьи находятся в карточках: [Cambridge — thank you](https://dictionary.cambridge.org/pronunciation/english/thank-you), [Cambridge — hola](https://dictionary.cambridge.org/dictionary/spanish-english/hola), [Larousse — bonjour](https://www.larousse.fr/dictionnaires/french-english/bonjour/10045).

Кнопка 🔊 использует синтез речи браузера. Доступность и качество озвучивания зависят от браузера и установленных голосов. При ошибке выводится предложение послушать произношение по словарной ссылке.

Язык интерфейса и оформление меняются только по нажатию **RU** или **EN**. Оригинальные фразы сохраняют свой язык. Форма остаётся учебным примером без серверного обработчика. Подвал не добавлен по ранее принятому решению для страницы.
